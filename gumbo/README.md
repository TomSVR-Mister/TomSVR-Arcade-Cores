# JTGUMBO (personal build)

FPGA implementation of Min Corp.'s 1994-95 board (Gumbo, Miss Puzzle, Miss Bingo, Double Point) for MiSTer.

- 68000 at 7.2 MHz, OKI M6295.
- 64x32 tilemap of 8x8x8 tiles (background) and 128x64 tilemap of 4x4x8 tiles (foreground), 512 colours.
- 60 Hz, 320x224 visible. Behaviour follows MAME's gumbo.cpp.

Built on [JTFRAME](https://github.com/jotego/jtcores) by Jose Tejada (jotego). GPL-3.0.
