# JTZERO (personal build)

FPGA implementation of Comad's 1993 board (Zero Zone, Las Vegas Girl) for MiSTer.

- 68000 at 10 MHz; Z80 at 4 MHz with an OKI M6295.
- One 64x32 tilemap of 8x8x4 tiles with tile banking, 256 colours.
- 60 Hz, 368x224 visible. Behaviour follows MAME's zerozone.cpp.

Built on [JTFRAME](https://github.com/jotego/jtcores) by Jose Tejada (jotego). GPL-3.0.
