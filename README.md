# comad-core (private)

Personal build of **jtcomad**, a fork of Jose Tejada's (jotego) JTGALS core with changes for the Comad
Gals Panic clones. See `comad/README.md` for the changes. Licence: GPL-3.0-or-later (same as the original).

## Build
Actions tab -> "Build Comad core" -> Run workflow. When it finishes (about 30-60 min), open the run and
download the `jtcomad-mister` artifact. The core is `release/mister/.../jtcomad.rbf` (exact path in the zip).

## Install on the MiSTer
Copy `jtcomad.rbf` to `/media/fat/_Arcade/cores/` and the jtcomad MRAs to `/media/fat/_Arcade/`.
